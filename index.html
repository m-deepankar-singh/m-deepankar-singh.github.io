Selected shorter work

  • GGUF → safetensors conversion + FP8 serving. Reverse-engineered llama.cpp's weight transforms to unlock vLLM serving for a GGUF-only 27B model — validated at >0.9999 per-tensor correlation; 135–185 tok/s at 262K context. Four artifacts published on Hugging Face — ~2,200 downloads in week one, 5,000+ to date.
  • MTP speculative decoding, ported to Trainium. 1.6× decode throughput on a standalone NxDI server — 44–48 tok/s against a ~27 tok/s baseline at speculation length 2 — with API validation across streaming, stop strings, and deterministic repeat.
